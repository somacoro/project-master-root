# 選好学習

## 原則
操作する根拠と、長期の好みとして学ぶ根拠を分離する。受容だけでは全ての特徴変化を好んだとみなさない。LLMが推測した「理由」を利用者の発言として保存しない。

## 差し替える方式
| ID | 根拠 | 実装段階 |
|---|---|---|
| no_update | 更新なし | 初期・比較用 |
| explicit_masked_delta | 現在発話の明示的言及と採用配置差分 | 旧基本式の再現用 |
| explicit_retained_delta | 明示的好み・配置評価を保持し、関連編集の採用差分で更新 | 今回の初週の実装・比較方式（12参照） |
| no_separation | 全ての採用差分 | 初期・比較用 |
| response_grounded | episode内の評価・訂正を統合 | 保持方式と重なる部分を整理し、別実験ではID・規則を明記 |
| repeated_edit | 上記と独立した局所編集の反復 | 後続、検証対象 |
| pairwise_choice | 複数提示案の選択 | 将来 |

## 既存式の再現用方式（今回の初週方式とは区別）
Δf=f(採用配置)-f(変更前の確定配置)
w_new=Π_{||w||2≤1}(w+η(q⊙Δf))
初期w=0、η=0.3、H=1を暫定の動作確認値とし、H=3も切替可能にする。既存の予備実験設定を再現する場合はH=3を明示する。H=1を有効性が確立した値として扱わない。
現在の発話で明示的な好みがある特徴だけqを非ゼロにする。現在を含む直近H件の利用者の編集要求について、同方向の言及数/Hを使う。ボタンのみの操作は要求数に含めない。この履歴単位は本システムの暫定定義。却下された要求も発話履歴には残すが、その配置差分では更新しない。
no_separationはq=1、no_updateはq=0。射影はノルム超過時だけ実施し、毎回単位長へ正規化しない。射影で非言及重みも縮小し得るため、「加算更新対象外」と「数値が不変」を区別する。

## 方向矛盾と限界
好みの言及極性eとΔfが逆方向の場合、その矛盾を記録する。忠実な式比較モードでは元の更新を行う。任意のdirection_guardモードではその成分を更新から除外する。両者は別設定として実験で混在させない。
採用案が元の案より真の効用で良い保証はない。マスク付き更新に従来の学習理論の保証がそのまま適用されるとは主張しない。好みだけを述べて配置が変わらなければ、この差分方式では重みは変わらない。その発言を根拠履歴に残し、explicit_retained_deltaでは、後続の関連する採用編集に紐づけて使う（12参照）。

## 修正と受容
プレビュー中は確定重みを更新しない。採用時に最後の確定配置からの差分を1回だけ学習する。修正の各段階を別の受容として数えない。
各修正の根拠にはproposal_id、episode_id、特徴、極性を記録する。episode内の明示的根拠を最終採用時に統合する方式では、同じ特徴の最新の明示的訂正を優先し、episodeにつき1回の根拠として扱う。基本式の「現在発話のみ」と異なるのでresponse_groundedとして区別する。
「いいね」は全体受容。「木に近いのは良い」は特徴への評価。「もっと寄せて」は要求未達の訂正候補。後者を直ちに一般的な好みの言及へ昇格させない。

## 反復学習の設計余地
学習候補にobject relation、要求方向、達成度、独立episode数、根拠、反対方向の履歴を保存する。独立した達成済みepisodeをまたぐ同方向の操作を証拠とし、一つの要求への再試行・エラー訂正を重複カウントしない。
回数閾値、対象の一般化、減衰、反証時の扱い、更新量は未決。初期はshadowモードで候補を記録するだけにし、重みに反映しない。後続方式は同じ保存ログで検証できるようにする。

## 自己強化の防止と監査
利用者が要求した変更、システムが選んだ変更、付随変化を区別する。更新ごとにbefore/after weights、raw delta、mask、projection scale、evidence IDsを保存する。推定重みだけで生成した案の受容を全特徴の強化に使う方式は比較用としてのみ明示する。

## 将来の比較学習
選ばれた案と提示された非選択案の特徴差を使う方式を別実装にする。未提示候補を利用者が拒否したとみなさない。「どれも嫌」「同程度」も表現可能にする。単一案の受容更新と暗黙に同一視しない。

## 今回の保持方式と反復の履歴
初週の「明示のみ」はexplicit_retained_deltaを指す。明示的評価、好み単独発話の保持、関連性判定、重複防止、未決設定は12に集約する。過去の根拠がある関連編集は、現在発話が局所操作だけでも学習対象となり得る。根拠が一切ない局所操作は加算更新しない。
操作ログは全件保存し、反復学習が参照する直近の独立した編集episode数は別設定にする。履歴窓、反復成立回数、減衰などを独立に設定する。異なるベンチをそれぞれ木に近づける等の関係変化を対象とし、単なる同方向の座標移動だけから一般化しない。具体的な閾値・更新式は未決。
